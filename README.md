# Конфликтология

Репозиторий исследовательского проекта по анализу конфликтов, разработке теоретической модели, методологии и программного прототипа.

## Рабочие направления
- `theory/` — теоретическая модель и понятийный аппарат.
- `methodology/` — методика и операционализация.
- `cases/` — эмпирические кейсы и материалы из открытых источников.
- `software/` — прототипы и код.
- `handoff/` — контрольные handoff-снимки проекта.
