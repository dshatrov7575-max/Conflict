## Confidence

Для старых ответов создан только LEGACY_AUDIT_ENVELOPE: исходный JSON без изменения содержания, SHA-256 первоначальных байтов, raw_confidence, encoding, meaning=NOT_DECLARED_IN_ORIGINAL_STANDALONE, cross_model_comparable=false, converted_category=null. Числа Claude не переводятся в HIGH/MEDIUM; исходные категории GPT не понижаются ради валидатора. Это не новая первичная форма и не допуск.

Для будущих C1-форм confidence — объект: kind=QUALITATIVE_UNCALIBRATED; value=HIGH|MEDIUM|LOW|UNKNOWN; meaning=CONFIDENCE_IN_RECORDED_CODING_DECISION; обязательный rationale. Категория независима от NUMERIC/UNKNOWN/DISPUTED. HIGH при UNKNOWN может означать уверенность в недостаточности свидетельства. Ни одна категория не является вероятностью, весом или автоматическим порогом выпуска числа.

## Временная область

SOURCE_STATEMENT описывает содержание конкретного датированного сообщения; AS_OF_SNAPSHOT описывает состояние на общую дату. Срез 2011-12-15T23:59:59Z остаётся отдельной невыполненной задачей.

Будущий C1 допускает только SOURCE_STATEMENT с новыми ID AO2S-C1-01…06, source_report_date, primary_evidence_id, as_of_time_utc=null и carry_forward_policy=NONE. Старые AO2-ID и декабрьский target не переименованы. Новые bindings — проект будущего входа, а не перенос ранее полученных чисел. Майские, августовские и октябрьские сообщения не объединяются автоматически в одновременные наблюдения. Дата публикации не считается точной датой события или доказательством устойчивости позиции.
