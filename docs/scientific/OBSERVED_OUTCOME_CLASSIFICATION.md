# Observed Outcome — справочник исторических исходов

Версия справочника: `0.1.0`. Применяется вместе с
[Validation Protocol](VALIDATION_PROTOCOL.md). Это номинальные категории
наблюдаемого прошлого, **не прогноз**, рейтинг или порядок интенсивности.

Названия категорий заданы задачей. Рабочие определения ниже — `PROPOSAL`
для проектирования разметки, а не утверждение об общепринятом измерительном
стандарте. До исследования необходимо зафиксировать отдельную кодировочную
инструкцию: единицу наблюдения, временное окно, географические границы,
допустимые источники, критерии включения и правила разрешения разногласий.
Эти критерии нельзя подбирать после просмотра сравнения с моделью.

| Код | Рабочее значение для исторической разметки | Ограничение |
| --- | --- | --- |
| `NO_ESCALATION` | При достаточном покрытии зарегистрированного окна не установлено ни одной из остальных квалифицирующих категорий. | Не означает отсутствие противоречий; нехватка источников не даёт права поставить эту метку. |
| `LOCALIZED_CONFLICT` | Документирован конфликт в ограниченной, заранее определённой локальной области. | Пространственный предел задаётся инструкцией; локальность сама по себе не определяет форму или интенсивность. |
| `MASS_PROTEST` | Документировано коллективное протестное действие, отвечающее заранее установленным критериям массовости. | Числовой порог не вводится этим PR; протест не считается насильственным автоматически. |
| `VIOLENT_CLASH` | Документирован эпизод столкновения с физическим насилием по критериям инструкции. | Не всякое такое столкновение является вооружённым конфликтом. |
| `ARMED_CONFLICT` | Документировано организованное вооружённое противостояние по отдельно закреплённым критериям. | Универсальный порог потерь или продолжительности не предполагается; нужен явный источник определения. |
| `INSTITUTIONAL_CRISIS` | Документирован кризис функционирования или преемственности политических институтов по критериям инструкции. | Политическое разногласие само по себе недостаточно для присвоения категории. |

Категории могут пересекаться: `classes` допускает несколько различных меток
с отдельным обоснованием в кодировочных материалах. Они не складываются и
не превращаются в баллы. `NO_ESCALATION` в данном справочнике несовместим
с остальными метками в одной записи; если периоды различаются, их нельзя
сливать в одно окно ради удобства классификации.

Неизвестный или неразрешённый спорный исход сохраняется как
`observed_outcome=null` с описанием причины в limitations. Пустой список
classes не обозначает NO_ESCALATION. Неразрешённые разногласия не скрываются
выбором наиболее удобной категории или статуса VALIDATED.

Заполненный observed_outcome содержит classes, непустые source_references,
coding_protocol_reference и notes (текст либо null). Ссылки закрепляют
конкретные артефакты и SHA-256. Источники исхода могут появиться после cutoff,
но используются только для независимой исторической разметки: их сведения
не должны попадать во входной snapshot или его factor mapping.

Категории не присваиваются из UNO и не используются как его вероятностная
интерпретация. Этот PR не классифицирует реальные эпизоды или страны.
Машиночитаемые допустимые значения находятся в
[VALIDATION_SCHEMA.json](VALIDATION_SCHEMA.json), в определении observed_outcome.
