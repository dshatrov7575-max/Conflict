Этот файл содержит только задания. Ключ, целевые якоря, типы заданий, разбор и распределение ответов кодеру не предоставляются. Пользоваться только [зафиксированной выдержкой рубрики](RUBRIC_FOR_CODERS.md); не искать внешние сведения. Сам факт раздельных файлов не обеспечивает слепоту: выдачу материалов должен контролировать организатор будущего пилота.

## Общие условия учебных ситуаций

- Каждая карточка — отдельная вымышленная единица. Актор А в одной карточке не связан с актором А в другой. Кодировать только фактор, названный в карточке.
- R — точный reference statement. Предмет нельзя менять. Целевая точка — день D, 12:00; эта же точка является учебным cutoff. Это относительное учебное время, не историческая дата.
- Если карточка не говорит об исключении, S1/S2 — аутентичные первичные записи прямой речи именно данного актора в целевой области; тексты приведены полностью, оригинал и контекст доступны, язык понятен, редакция существовала к учебному cutoff. Атрибуция и связь с R установлены; других относящихся к единице сообщений нет.
- Актор по умолчанию индивидуален. Если задана группа, применяется только явно описанное основание представительства. Исключения в карточке важнее общих допущений.
- Утверждения о подлинности/доступности — условия вымышленной задачи, не результат архивной проверки. Условные S1/S2 не являются реальными Evidence IDs. G1–G4 проверяются относительно условий сценария; это не обход их требований для реального кейса.
- G7 относится к организации будущего HUMAN пилота. Здесь задан учебный вопрос: какой ответ разрешила бы рубрика при описанных условиях? Реального HUMAN сеанса, допуска исторических данных или формальной preregistration этим пакетом не создаётся.
- Для KVS буквы A/B/C обозначают вопросы повестки, а актор А — говорящего. Полная повестка и доступность альтернатив заданы в контексте каждой карточки; нельзя добавлять собственные альтернативы.

## Что должен вернуть будущий независимый кодер

Для каждой карточки отдельно: ID; фактор; допускает ли рубрика один числовой якорь либо требует UNKNOWN/DISPUTED; при единственном якоре — его метка; точные слова S1/S2, на которых основан выбор; применённые пункты рубрики; отвергнутый соседний якорь и различающий признак; confidence и его предмет; замечание о недостаточном/неоднозначном правиле.

Форма ответа описана для будущего пилота. Здесь ответов нет. При неоднозначности запрещено угадывать intended answer, выбирать середину или исправлять рубрику. Частичное качественное наблюдение записывается отдельно от отсутствующего числа. Для DISPUTED требуется описать альтернативы; единое число не выбирается.
