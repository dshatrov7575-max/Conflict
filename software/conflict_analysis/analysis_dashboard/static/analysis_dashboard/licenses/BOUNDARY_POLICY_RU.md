# CA_BOUNDARY_POLICY_V1

Набор CA_CENTRAL_ASIA_POLITICAL_V1, версия 1.0.0. Natural Earth release
5.1.2: ADM0 countries 5.1.1; disputed/claim lines 5.1.0. Слой государств
использует исходную de facto картографическую классификацию Natural Earth.
Обычные границы — сплошные тёмные линии. Спорные и претензионные линии —
фиолетовый пунктир с подложкой; они не заменяются границей одной из сторон.
Исходные классификации и disputed attributes сохранены в GeoJSON.

Этот слой отражает выбранную картографическую версию и не является
юридическим заключением о статусе спорных территорий.

geoBoundaries KAZ-ADM1-16772668 используется только для внутренних областей
Казахстана: исторический срез **2017 года**, 16 единиц; он не отражает
последующие административные реформы. Государственные контуры этого набора
не используются вместо Natural Earth. Исходные ADM1-полигоны показаны как
контекст; несовпадение линий наборов возможно и не исправляется вручную.

Область отображения [40,30,100,65], EPSG:4326. Упрощение 0.01 градуса
с сохранением топологии каждой геометрии. Такая карта не предназначена для
землеустройства, измерения границ или точной навигации. Центр REGION/AREA
не обозначает точную географическую границу конфликта; радиус обязателен.

Обновление: отдельное согласование владельца, новые raw hashes и licenses,
повтор build_dataset.py, topology/browser QA, новая версия manifest и новые
immutable GeographicArea identities. Изменение политики требует новой
dataset_version. Исторические ProjectLocationRevision сохраняют прежний pin.
