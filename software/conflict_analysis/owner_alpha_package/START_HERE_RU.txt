Анализ конфликтов — функциональная альфа 0.1.0-alpha.1
Кандидат для проверки. Не production-ready и не релиз.

Требования: Windows 11 x64, уже работающая WSL2 с виртуализацией,
PowerShell 7 и Microsoft Edge. Интернет после получения пакета не требуется.
Пакет ничего не устанавливает и не обновляет в Windows, не повышает права,
не меняет политики, доверие, защиту, настройки Edge или WSL хоста.

1. Получите один точный ZIP и независимую запись его размера и SHA-256
   из принятого канала доставки. Распакуйте полностью в отдельную локальную
   папку. Не смешивайте версии и не изменяйте файлы внутри этой папки.
2. Запустите INSTALL_CONFLICT_ANALYSIS.cmd.
3. Запустите START_CONFLICT_ANALYSIS.cmd. Откроются три отдельные профиля:
   STUDIO_EDITOR — структура; STUDIO_PUBLISHER — проверка и публикация;
   PLAYER_ASSESSOR — рабочие пространства, оценки, XLSX и evidence.
   Для предоставления доступа Publisher и Player введите точный UUID
   созданного проекта в оставшемся окне Start и подтвердите GRANT.
   Без этого отдельного действия проект для них не открывается.
4. STOP_CONFLICT_ANALYSIS.cmd безопасно останавливает среду и отзывает сессии.
   Следующий Start использует прежние Django user PK и новые сессии.
5. DIAGNOSTICS.cmd показывает состояние и идентичности без секретов.
6. BACKUP_CONFLICT_ANALYSIS.cmd требует подтверждение BACKUP <instance>.
   Это приватная полная копия БД и уже сохранённых оригиналов.
   Файл хранится в закрытой папке состояния и не отправляется в GitHub.
   Не заменяйте её экспортом Foundation 2.2.
7. RESTORE_CONFLICT_ANALYSIS.cmd принимает только известную этому экземпляру
   приватную копию с отдельной записью происхождения. Восстановление идёт
   в новую изолированную среду. После полной проверки можно отдельно
   подтвердить SWITCH <candidate instance>. Исходная среда сохраняется.
8. RESET_CONFLICT_ANALYSIS.cmd создаёт резервную копию и новую пустую среду.
   Отдельное подтверждение SWITCH выбирает её активной.
9. UNINSTALL_CONFLICT_ANALYSIS.cmd требует UNINSTALL <instance>, сначала
   создаёт приватную копию, затем удаляет только точный дистрибутив пакета.
   Исходный ZIP и приватные резервные копии сохраняются.

Если показан BLOCKED_G10_*, не повторяйте вслепую запись или импорт.
BUSY означает незавершённую операцию; UNKNOWN — неподтверждённый исход.
Сохраните публичный код отказа и обратитесь к сопровождающему проверки.
Не удаляйте профили вручную, не меняйте политики и не снимайте метки зоны.

Если действующая политика не разрешает эти точные скрипты, запуск остановится
до импорта. У кандидата нет заявленной цифровой подписи. Internet-marked
unsigned файлы при RemoteSigned не допускаются. Наличие локального успешного
пробного запуска не заменяет обязательную проверку окончательного ZIP (L05).

Никаких вычислений Power, риска, вероятности, прогноза, рекомендаций,
автоматического победителя или заполнения неизвестных значений пакет
не добавляет. UNKNOWN и числовой ноль различаются.

Прекодовая квалификация LM-STUDIO принята отдельно. Реальные Windows 2/2
и offline L05 окончательного ZIP ещё требуют подтверждённого канала и
независимых доказательств. До них пакет не разрешён для owner test или релиза.
