MVP7 R1 — тестовый кандидат, не производственный релиз.
Источник приложения: 85a253126bf270664c4786d159994e7359b5d2c5.
Установка: Windows 11 x64, уже работающая WSL2, PowerShell 7, Microsoft Edge.
Программа не устанавливает prerequisites и не меняет политику исполнения.
Установите ConflictPartnerDemo_MVP7_Setup.exe. Все данные находятся внутри архива;
сеть при установке и работе не требуется. Три изолированных профиля Edge:
редактор, публикатор, оценщик. У публикатора открываются Studio и «Аналитика»
с картой; у оценщика — Player (Analysis доступен по /analysis/ в том же профиле).
Редактор сохраняет Studio scope без доступа к данным Analysis/Geography.
Демонстрационный проект Жанаозена содержит синтетические исходные данные.
Программа: %LOCALAPPDATA%\Programs\ConflictPartnerDemo\MVP7.
Состояние, WSL-диск и backups: %LOCALAPPDATA%\ConflictPartnerDemoState\mvp7.
Удаление программы сохраняет состояние, WSL-дистрибутив и backups.
При незавершённой установке не удаляйте состояние: сохраните его для диагностики.
